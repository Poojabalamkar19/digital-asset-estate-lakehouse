# Digital Asset & Estate Intelligence Platform

## Project Overview

An end-to-end Data Engineering project built using
Databricks, PySpark, Delta Lake and Python.

The platform processes digital asset, ownership,
transaction, valuation and estate beneficiary data.

## Technologies

- Python
- PySpark
- Databricks
- Delta Lake
- Databricks SQL
- Unity Catalog
- Git and GitHub
- Power BI

## Architecture

Medallion Architecture:

- Bronze: Raw data ingestion
- Silver: Data cleaning and validation
- Gold: Business-ready analytical datasets
